# Agent rules

## Writing style: Simplified Technical English (STE-style)

Write all chat replies, code comments, and docs in STE-style English.
This is not certified ASD-STE100. It follows the main rules.

Rules:

- Write short sentences. Use one instruction in each sentence.
- Use the active voice. Do not use the passive voice.
- Use simple words. Use one word for one meaning.
- Use the same word for the same thing every time.
- Do not use a gerund when a plain verb works.
- Use the present tense for facts.
- Use the imperative for steps.
- Do not use idioms.
- Do not use filler words or buzzwords.

Limits:

- I cannot check text against the licensed ASD-STE100 dictionary.
- I have no STE checker tool. I can make errors that I cannot find.
