## SAT12

This project is based on the original work found in [gabo](https://github.com/phylecorp/gabo), which was built during the **[Nebula:Fog hackathon](https://nebulafog.ai)**. Big thanks to the original authors for building this—it was a great conversation about rewriting history. I'm very grateful.

In plain English, **SAT12** is an automated "deep-dive" research tool. Instead of just giving you a quick AI answer, it follows a rigorous intelligence process to make sure the result is accurate and well-supported. It saves everything in an [OKF wiki](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) and can pull in previous research from there if it's relevant. It also takes local files and folders as evidence, meaning it combines previous research, your own files, and live web searches into one big picture.
